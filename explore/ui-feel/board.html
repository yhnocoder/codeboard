初版约定

原则：动效只用来说明「东西从哪来、到哪去」；交互按桌面软件的习惯来，不按网页。打开「¼ 慢放」看动效最清楚。

动效

展开一层

行先闪一下，卡片从这一行旁边弹出，连线一头钉在调用行、一头始终接在卡片标题上，跟着卡片一起伸出去。弹簧几乎不过冲。

镜头

新卡片在视野里就不动镜头；跑出去了才平滑跟过去，用不过冲的弹簧，绝不瞬移。

重复展开

不再新建卡片：镜头飞到已有的那张，卡片外圈扩散一次，提示原地刷新、不堆叠。

拖拽

按下立即抬起（阴影变深、放大 1.2%），跟手 1:1，没有延迟；松手轻轻落下。

拖标题栏
平移与缩放

拖空白处平移，松手带惯性滑一小段。按钮缩放用弹簧，滚轮捏合则完全跟手，以光标为中心。

菜单

从触发点长出：进 140–160ms 减速，出 90ms 加速。出总比进快。

讲解

镜头在卡片间飞，其他卡片淡到 28%。←/→ 切换，Esc 退出。

删除

选中后按 Delete：卡片缩小淡出 140ms，连线沿原路缩回去。

新版本

琥珀点出现时脉冲一次，之后静止。不做循环闪烁。

手感

选中只有代码能选中复制，选区连续，复制出来不带行号。按钮、标题、行号都选不中。
⌘A选中全部卡片，不选文字。Esc 取消，Delete 删除。
改名双击卡片标题直接改，回车确认，Esc 放弃。
右键卡片和画布各有自己的菜单，不出现浏览器的剪切 / 复制 / 粘贴。
光标按钮上是箭头，靠底色说明能点；只有可点的代码调用名用小手。
焦点框鼠标点击不留框，用 Tab 键盘操作时才出现。
按压按下立刻变深、缩小，没有过渡；松开再弹回。
提示停 500ms 出现并带快捷键；之后在按钮间滑动立刻切换；按下即消失。
其他图标拖不出残影；滚动不带着页面跑；会变化的数字用等宽字体；代码字体跟随 VS Code 编辑器设置，字号由白板缩放决定。
刻意不做：hover 时卡片上浮；页面打开时的整体淡入；循环呼吸灯；按钮点击后的波纹。系统设了「减少动态效果」时全部变成直接切换。

需要你拍板的几件事

  1. 按钮光标用箭头还是小手？我倾向箭头，和以后的 macOS app 一致；但 VS Code 自己用小手。
  2. 代码卡片里的代码可以选中复制吗？我倾向可以，拖动只能从标题栏拖。代价是代码区不能直接拖卡片。
  3. 右键菜单要放哪些操作？格子 07 是我的初稿。
  4. 代码字体和字号要跟随 VS Code 的编辑器设置吗？我倾向跟随字体、不跟随字号，白板有自己的缩放。
